# images

사이트에 쓰일 사진을 이 폴더에 넣습니다.

## 올리기 전에 용량을 줄여주세요

카메라에서 바로 나온 사진은 보통 한 장에 5–15MB입니다. 그대로 올리면
방문자가 페이지를 열 때마다 그만큼을 내려받아야 해서 사이트가 매우
느려집니다.

권장 기준:

| 항목 | 값 |
|---|---|
| 가로 길이 | 최대 2000px |
| 파일 크기 | 한 장당 500KB 이하 |
| 형식 | JPG (또는 WebP) |

맥에서는 **미리보기** 앱으로 간단히 줄일 수 있습니다.
사진을 열고 → 도구 → 크기 조정 → 가로 2000px → 파일 → 내보내기에서
JPEG 품질을 조절해 저장하면 됩니다.

## 파일 이름

한글과 공백은 웹 주소에서 깨질 수 있습니다. 영문 소문자와 하이픈을
쓰는 편이 안전합니다.

```
좋음:   wedding-sunset-01.jpg
피하기:  김민지님 최종 (1).jpg
```

## 사이트에 반영하기

파일을 넣은 뒤 `index.html`의 사진 섹션에서 자리 표시용 블록을
아래 형태로 바꿔주세요.

```html
<figure class="photo">
  <img src="images/wedding-sunset-01.jpg"
       alt="해질 무렵 야외 예식장에서 마주 선 신랑과 신부"
       loading="lazy" width="1600" height="1067">
</figure>
```

`alt`에는 사진 내용을 설명하는 문장을 적어주세요. 눈이 불편한 방문자가
쓰는 화면 낭독기가 이 문장을 읽어주고, 검색 엔진도 이 텍스트를 참고합니다.

## 다른 사람이 나오는 사진

의뢰인이나 모델이 찍힌 사진을 공개 저장소에 올리면 인터넷 전체에
공개됩니다. 게재 동의를 받은 사진인지 먼저 확인해주세요.
