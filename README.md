# greynomy

사진과 영상 작업을 소개하는 포트폴리오 웹사이트입니다.

## 개요

외부 라이브러리나 빌드 도구 없이 HTML·CSS·JavaScript만으로 만들었습니다.
설치할 것이 없고, `index.html`을 브라우저에서 바로 열면 그대로 동작합니다.

- 사진은 세로·가로가 섞여도 자연스럽게 배치되고, 누르면 크게 볼 수 있습니다
- 영상은 썸네일만 먼저 보여주고 누를 때 재생기를 불러옵니다
- 화면 크기에 따라 배치가 바뀌며, 시스템 설정에 따라 밝은 화면으로도 표시됩니다

## 저장소 구조

```
.
├── index.html          사이트 본문
├── assets/
│   ├── css/style.css   색·여백·배치
│   └── js/main.js      확대 보기, 영상 재생
├── images/             사진을 넣는 곳 (사용법은 images/README.md)
└── README.md
```

## 시작하기

저장소를 로컬에 복제합니다.

```bash
git clone https://github.com/simpeach/greynomy.git
```

`index.html`을 더블클릭하면 브라우저에서 열립니다.

파일을 고친 뒤 새로고침하면 바로 반영됩니다. 다만 일부 브라우저는
파일을 직접 열었을 때 보안 정책으로 동작이 제한될 수 있어, 아래처럼
간단한 서버를 띄우고 `http://localhost:8000`으로 접속하는 편이 확실합니다.

```bash
python3 -m http.server 8000
```

## 내용 수정하기

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 사진 추가·교체 | `images/` 폴더 + `index.html`의 사진 섹션 |
| 영상 추가 | `index.html`의 `data-youtube` 값 |
| 소개 글, 연락처 | `index.html`의 소개·연락 섹션 |
| 색상, 글꼴, 여백 | `assets/css/style.css` 맨 위 `:root` 블록 |

`index.html` 안에 주석으로 각 부분의 수정 방법을 적어두었습니다.

## 영상 파일에 대하여

영상은 저장소에 직접 올리지 않습니다. git은 용량이 큰 이진 파일에
약해서, 한 번 커밋하면 나중에 지워도 기록에 남아 저장소가 계속
무거워집니다. GitHub도 파일 하나가 100MB를 넘으면 푸시를 거부합니다.

YouTube나 Vimeo에 올린 뒤 링크로 연결해주세요. `.gitignore`에 영상
확장자를 미리 넣어두어 실수로 커밋되지 않도록 해두었습니다.

## 기여하기

1. 작업할 브랜치를 새로 만듭니다 (`git checkout -b my-change`)
2. 변경 사항을 커밋합니다
3. 브랜치를 푸시하고 Pull Request를 엽니다

`main`에 직접 커밋하지 않고 브랜치와 PR을 거치면, 변경 이력이 남고
되돌리기도 쉬워집니다.

## 라이선스

아직 라이선스가 지정되지 않았습니다. 라이선스가 없는 저장소는 기본적으로
모든 권리가 저작자에게 유보되므로, 공개적으로 활용될 여지를 두려면
`LICENSE` 파일을 추가해주세요.

사진과 영상 등 작업물의 저작권은 코드 라이선스와 별개입니다. 코드에만
라이선스를 적용하고 작업물은 제외하려면 그 사실을 명시해주세요.
